# Blueprint Skill

Setiap package menggunakan canonical ALOS `SkillDefinition` dalam `skill.yaml` dan data prosedural
dalam `SKILL.md`. Discovery metadata bukan authorization; hanya exact Skill refs dari Backend yang
dapat dipilih dan dimuat secara progresif. Package tidak executable dan tidak membawa authority.

Skill yang dibuat AI tetap draft sampai Backend authority mereview dan mengaktifkannya.
