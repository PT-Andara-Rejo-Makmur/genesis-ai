# Governed deterministic business assistant

ARA extends AgentRuntimeEngine and ModelGatewayAgenticPlanner. GovernedModelGateway owns the deterministic route,
classification ceiling and remaining token/cost bounds. BusinessAssistantPlanner supplies structured owner observations,
Backend-authorized tool identifiers and server-bound resource arguments. DeterministicBusinessAdapter does not treat
source text as executable instructions and cannot invent authority or a missing source.

Successful ToolResult evidence is admitted only with current/valid status, matching identity, scopes, classification,
run, correlation and a verified content hash. Final factual decisions require known evidence. Empty sources and unknown
values remain distinct; source failures stop the runtime without fabricated business values.

Backend controls one optional business reader child and invokes this same runtime with narrowed tool and permission
allowances. Existing delegation, cycle, depth, budget and cancellation foundations remain in place. GENESIS has no direct
business database connection. Research uses ResearchEngine behind GovernedModelGateway with current internal evidence.
No production provider, provider key, provider SDK, 9Router or Hermes is introduced.
